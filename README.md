# My Portfolio Website

![Portfolio Preview](assets/preview.png)

A modern, responsive personal portfolio website built to showcase my web development projects, skills, and experience.

## ✨ Features

- **Fully Responsive** – Works beautifully on desktop, tablet, and mobile
- **Smooth Scrolling Navigation**
- **Interactive Project Gallery** with live demo and GitHub links
- **Contact Form** (ready for Formspree / EmailJS)
- **Clean & Modern Design** with hover animations
- **SEO-friendly** structure
- **Easy to Customize** – just edit the content!
